# PR #1135 mathematical verification figures

Generated by comparing the previous clipped `Φ` implementation with the
`scipy.special.log_ndtr` implementation.

- In the **safe** region (`1e-9 < Φ(X) < 1-1e-9`) the two methods agree to
  near machine precision (algebraic identity).
- In the **tail**, clipping flattens `log Φ` and drives `φ/Φ → 0`; `log_ndtr`
  matches SciPy / adaptive quadrature references.
