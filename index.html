GPy

Gaussian process modelling in Python, from the Sheffield machine learning group. GPy covers regression, classification, sparse GPs, coregionalization, kernels, and latent-variable models. We pronounce it “g-pie”.

This page is a pointer. Install, usage, and contributing live in the GitHub README. We keep those sources current; we do not duplicate them here.

Install

pip install gpy from PyPI. Optional plots: pip install 'gpy[plotting]'.
