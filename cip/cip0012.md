# CIP-0012: Fix numerical stability defects catalogued by the CIP-0011 suite

## Status

- [x] Proposed - Initial idea documented
- [ ] Accepted - Approved, ready to start work
- [ ] In Progress - Actively being implemented
- [ ] Implemented - Work complete, awaiting verification
- [ ] Closed - Verified and complete
- [ ] Rejected - Will not be implemented
- [ ] Deferred - Postponed

## Summary

Remediate the **11 numerical defects** recorded as
`xfail(strict=True)` in the CIP-0011 suite. Prefer small, local fixes
(`gammaln`, `logaddexp` / `expm1`, direct pairwise distances, raise on
non-finite Cholesky input, remove debugger breakpoints). Each fix PR
removes the matching xfail in the same change so XPASS does not linger.

Progress is measurable with CIP-0011's cross-branch comparer:
`--baseline main --candidate <fix-branch>`.

## Motivation

The stability suite (draft: `test_numerical_stability.py`) exercises
extreme but representable inputs. Failures are not exotic edge-case
noise:

| Severity | Example impact |
|----------|----------------|
| Crash / hang | Leftover `ipdb` breakpoints when Laplace / DTC / state-space hit NaN — unattended jobs hang if `ipdb` is installed, `ModuleNotFoundError` if not |
| Wrong science on ordinary data | Gamma + Laplace overflows for `y ≈ 150–1100` via `log(gamma(alpha))` |
| Silent corruption | Stationary kernels lose translation invariance at offsets ~1e6–1e9 (Unix timestamps); Exponential/OU `K(X,X)` vs `K(X,X2)` disagree at duplicates |
| Optimiser / EP failure | Bernoulli clip floors log-likelihood; EP variance can go negative; all-params-at-bound yields NaN gradients with finite objective |

Leaving these as permanent xfails would freeze a green suite that
documents broken contracts. This CIP is the remediation track.

## Detailed Description

### Dependency on CIP-0011

- **Blocked for merge of fixes that only touch tests:** CIP-0011 should
  house the suite first (or the same PR can land both the move and the
  first fix batch — Accept decides).
- **Not blocked for exploratory fix branches:** developers may patch
  `GPy/` against the root draft file before the suite is relocated.
- After each fix: remove the corresponding `xfail`; run
  `pytest numerical_stability/` and
  `compare.py --baseline main --candidate HEAD` expecting **improvements**,
  zero regressions.

### Defect catalogue (priority order)

Priorities: **P0** crash / silent NaN on common paths; **P1** large
numerical error on realistic data; **P2** tail / extreme-input
correctness; **P3** hygiene.

#### P0 — Debugger breakpoints on numerical error paths

- **Sites:** `GPy/inference/latent_function_inference/laplace.py` (NaN
  objective), `GPy/inference/latent_function_inference/var_dtc.py`,
  `GPy/models/state_space_main.py` (confirm exact lines via the suite's
  AST hygiene test).
- **Fix:** remove `ipdb` / `pdb` / `breakpoint()` on those paths; log
  and raise or return a controlled failure. Never gate library code on
  an interactive debugger.
- **Test:** hygiene test flips from xfail → pass; Gamma+Laplace crash
  path stops being an import error.

#### P0 — Gamma likelihood overflow

- **Cause:** `log(special.gamma(alpha))` overflows for `alpha > ~171.6`.
- **Fix:** use `scipy.special.gammaln` (or equivalent) in
  `Gamma.logpdf_link` (and any sibling paths).
- **Test:** count/positive likelihood + Laplace Gamma model xfails.

#### P1 — Stationary kernel distance cancellation

- **Cause:** `Stationary._unscaled_dist` expands
  `|x|² + |x'|² − 2x·x'`; shared large offset destroys precision
  (error ~1e-3 at 1e6, ~0.8 at 1e8).
- **Fix:** compute differences directly (or centre inputs inside the
  distance helper). Preserve Cython parity if the compiled path has the
  same expansion (CIP-000E awareness: fix both Python and Cython, or
  document a single source of truth).
- **Test:** `test_stationary_translation_invariance_large_offset`.

#### P1 — Exponential / OU at coincident points via `K(X, X2)`

- **Cause:** `K(X, X2)` path lacks the `r=0` fix-up used on the `K(X)`
  diagonal; expanded `r² ~ 1e-16` → `r ~ 1e-8` → cusp kernels return
  `k = 1 − 2e-8`.
- **Fix:** apply the same zero-distance fix-up on the `X2` path (or
  shared helper).
- **Test:** `test_K_with_X2_equal_X_is_consistent` for Exponential/OU.

#### P1 — Bernoulli / probit likelihood

Three related defects:

1. **Probability clip at 1e-9** floors `log p` at ~−20.7 (true value at
   `f = −10` is ~−53) and kills gradients for confidently wrong labels.
2. **Third derivative** → −inf for `f > ~8.3` (clip inconsistency).
3. **EP moment match** can yield **negative posterior variance** in
   extremes (`sigma2_hat` cancellation for large `|z|`).

**Fix direction:** use stable `log_ndtr` / clipped-in-log-space
formulations consistently across logpdf and derivatives; rewrite EP
variance with a numerically stable expression (or clamp with an
explicit, tested bound and warning — Accept prefers true stability
over silent clamp).

#### P2 — Softplus link (`Log_ex_1`)

- **Cause:** `log1p(safe_exp(f))` saturates once `safe_exp` clips at
  `log(DBL_MAX)` (~709), so softplus stops returning `≈ f`.
- **Fix:** stable softplus (`logaddexp(0, f)` or branch on large `f`
  return `f`).

#### P2 — Cloglog link

- **Cause:** `1 - exp(-exp(f))` underflows to 0 for `f ≲ −20`.
- **Fix:** use `expm1` / `-expm1(-exp(f))` carefully, or compute in
  log-space where callers need it.

#### P2 — `jitchol` non-finite input

- **Cause:** trusts LAPACK `info==0` and returns factors containing
  NaN/inf instead of raising when the input itself is non-finite.
- **Fix:** reject non-finite entries before the factorisation (or
  treat as `LinAlgError` / `ValueError`).

#### P2 — Poisson logpdf for large negative `f`

- **Cause:** `y * log(exp(f))` underflows `exp(f)` to 0 below
  `f ~ −745` → NaN.
- **Fix:** `y * f` (with care for `y=0`) instead of `y * log(exp(f))`.

#### P2 — NaN gradient when every parameter is at its lower bound

- **Cause:** objective finite; gradient has NaNs when all positive
  parameters sit on the Logexp floor (~5.6e-309).
- **Fix:** investigate paramz / transformation chain (may overlap
  CIP-000F); at minimum, guard transforms so finite objectives yield
  finite gradients at bounds, or document and skip with a linked
  CIP-000F task if the root is paramz.

### Out of scope / documented non-bugs

- **Cosine kernel** in `input_dim > 1` is not a valid covariance —
  suite tests 1D only.
- **Student-t + Laplace** at very small scale (`σ² = 0.01`) fails
  gradient checks; suite only asserts settings that currently pass.
- **SVGP** test skipped without optional `climin`.

### Fix packaging

Prefer **small PRs**, one theme each (breakpoints; Gamma; stationary
distances; Bernoulli/EP; links; jitchol; Poisson; bound gradients).
Each PR:

1. Code fix (+ Cython twin if needed).
2. Remove matching `xfail`(s).
3. `uv run pytest GPy/testing numerical_stability/` green.
4. Optional: paste `compare.py` summary vs `main` in the PR body.

## Implementation Plan

1. **Land or sync with CIP-0011** so the suite path is stable.
2. **P0 batch:** breakpoints + Gamma `gammaln`.
3. **P1 batch:** stationary distances (+ Cython) and Exponential/OU
   `K(X,X2)` fix-up.
4. **P1 batch:** Bernoulli / EP stability.
5. **P2 batch:** softplus, cloglog, jitchol, Poisson.
6. **P2/P3:** bound-gradient NaN (or defer with explicit link to
   CIP-000F if root-caused there).
7. **Close:** zero strict xfails remain in the suite for this
   catalogue; compare vs pre-fix `main` shows only improvements.

## Backward Compatibility

- Behaviour changes are **corrections** toward mathematically expected
  values. Callers that relied on clipped Bernoulli log-likelihoods or
  saturated softplus may see different numeric values; that is
  intentional.
- Raising on non-finite `jitchol` input may turn silent NaN likelihoods
  into earlier exceptions — preferable for debugging.
- Removing debugger breakpoints can only improve unattended runs.

## Testing Strategy

- CIP-0011 suite is the acceptance oracle: each defect's xfail → pass.
- Full `GPy/testing` must stay green (no collateral damage).
- Cross-branch: `compare.py --baseline main --candidate <branch>` after
  each batch; regressions fail the compare.
- For distance / Cython changes: assert Python and Cython paths agree
  on a shared fixture (offsets, duplicates).
