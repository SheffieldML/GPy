## Summary

Add two skewed continuous likelihoods to `GPy.likelihoods`, historically used for
Ferrari Formula 1 lap-time modelling:

1. **SkewGaussian** — probit × Gaussian (O'Hagan & Leonard 1976 / Azzalini skew-normal)
2. **SkewExponential** — probit × bilateral exponential (Laplace base; same product construction)

Both support Laplace inference via `logpdf` / `dlogpdf_df` / `d2logpdf_df2` /
`d3logpdf_df3` and hyperparameter gradients, with gradient-check tests.

## Motivation

Lap times are asymmetrically noisy: a car is more often slower than a latent
"pace" than faster. A symmetric Gaussian understates the right tail. The
O'Hagan construction multiplies a symmetric base density by a probit
:math:`\Phi(\alpha e)` to introduce controlled skew while remaining a proper
density. These models existed in earlier Ferrari / MATLAB work but were never
ported to GPy.

## Detailed Description

### Shared construction

If :math:`g` is a density symmetric about 0 and :math:`G` is any continuous CDF
symmetric about 0, then

.. math::

    p(e) = 2\, g(e)\, G(\alpha e)

is a density (Azzalini; special case O'Hagan & Leonard 1976 for Gaussian
:math:`g` and :math:`G=\Phi`).

### SkewGaussian

.. math::

    p(y\mid f)
    = \frac{2}{\sigma}\,
      \phi\!\left(\frac{y-f}{\sigma}\right)
      \Phi\!\left(\alpha\frac{y-f}{\sigma}\right)

Parameters: `variance` (:math:`\sigma^2`, Logexp), `alpha` (unconstrained).
Identity link. :math:`\alpha=0` recovers `Gaussian`. Closed-form conditional
mean/variance via the usual skew-normal formulae.

### SkewExponential

The one-sided exponential is not symmetric, so the factor-of-two construction
does not apply directly. The matching choice is the **Laplace** (double
exponential) base :math:`g(e)=(\lambda/2)\exp(-\lambda|e|)`, giving

.. math::

    p(y\mid f)
    = \lambda\,
      \exp\!\bigl(-\lambda\,|y-f|\bigr)
      \Phi\!\bigl(\alpha(y-f)\bigr).

Parameters: `rate` (:math:`\lambda`, Logexp), `alpha` (unconstrained).
Named `SkewExponential` to match the historical "probit × exponential" phrasing;
the docstring states the bilateral-exponential base explicitly.

### Inference

No exact conjugate GP regression. Use Laplace (primary) or EP quadrature
(default `moments_match_ep` on the base class). Hyperparameter gradients follow
the Student-t pattern (`dlogpdf_link_dtheta`, …).

### Numerics

Inverse Mills ratio :math:`\varphi/\Phi` and derivatives live in
``GPy.util.gaussian_special`` (vectorized via ``scipy.special.log_ndtr``),
shared with the style of Bernoulli–Probit. The same module re-exports SciPy
``wofz`` / ``erfcx`` for LFM / SIM (``EQ_ODE1``, ``EQ_ODE2``), which are the
complex / scaled-erf extensions of the same Gaussian-tail arithmetic.

**Faddeeva / ``wofz``:** SciPy has first-class ``scipy.special.wofz`` and
``erfcx``. Since SciPy 0.12 (2012) these use Steven G. Johnson's Faddeeva C++
package, replacing the old ACM TOMS 680 Fortran ``WOFZ``. GPy has no Fortran
Faddeeva of its own to drop; EQ_ODE kernels already call SciPy. The orphaned
``kern/src/sympy_helpers.cpp`` ``erfcx`` belongs to the removed symbolic-AD
stack (CHANGELOG / CIP-000E) and is not built.

## Implementation Plan

1. Add `GPy/likelihoods/skewed.py` with `SkewGaussian` and `SkewExponential`
2. Export from `GPy.likelihoods`
3. Add focused unit tests: log-density vs SciPy / finite difference, link and
   parameter gradients via `GradientChecker`, Laplace fit smoke test,
   serialization
4. Factor Mills / Faddeeva helpers into `GPy.util.gaussian_special` and wire
   skewed likelihoods + EQ_ODE kernels
5. Update this CIP status after tests pass

## Backward Compatibility

Additive only. No changes to existing likelihood APIs.

## Testing Strategy

- `logpdf` of `SkewGaussian` matches `scipy.stats.skewnorm.logpdf`
- Gradients of log-likelihood w.r.t. `f`, `variance`/`rate`, and `alpha` pass
  finite-difference checks
- `SkewGaussian(alpha=0)` matches `Gaussian` logpdf (up to numerical noise)
- Laplace regression smoke test on synthetic skewed noise
- `to_dict` / `from_dict` round-trip
