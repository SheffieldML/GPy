## Summary

Remediate the **11 numerical defects** recorded as
`xfail(strict=True)` in the CIP-0011 suite. Prefer small, local fixes
(`gammaln`, `logaddexp` / `expm1`, direct pairwise distances, raise on
non-finite Cholesky input, remove debugger breakpoints). Each fix
removes the matching xfail in the same change so XPASS does not linger.

Progress is measurable with CIP-0011's cross-branch comparer:
`--baseline main --candidate <fix-branch>`.

**Implementation note (2026-11-17):** landed on branch
`cip0011-numerical-stability` together with the CIP-0011 suite. Suite
result after fixes: **407 passed, 0 xfailed, 1 skipped**.

**Follow-up (2026-11-21):** PR CI exposed a secondary defect once bound
gradients stayed finite at the Logexp floor — DiffKern / RBF
`1/ℓ²` paths overflowed at subnormal lengthscales. Hardened; suite adds
`test_rbf_diffkern_finite_at_subnormal_lengthscale`.

## Motivation

The stability suite exercises extreme but representable inputs. Failures
were not exotic edge-case noise:

| Severity | Example impact |
|----------|----------------|
| Crash / hang | Leftover `ipdb` / `pdb` breakpoints when Laplace / DTC / state-space hit NaN |
| Wrong science on ordinary data | Gamma + Laplace overflows for `y ≈ 150–1100` via `log(gamma(alpha))` |
| Silent corruption | Stationary kernels lose translation invariance at large offsets; Exponential/OU `K(X,X)` vs `K(X,X2)` disagree at duplicates |
| Optimiser / EP failure | Bernoulli clip floors log-likelihood; EP variance can go negative; all-params-at-bound yields NaN gradients with finite objective |
| Platform CI (follow-up) | Bound-grad NaN→0 lets optimize settle at ~1e-300 lengthscales; DiffKern then overflows → Windows 3.11 `MultioutputGP` prod-mix post-`optimize` `checkgrad` fails |

## Detailed Description

### Fixes landed

| Defect | Fix |
|--------|-----|
| Debugger breakpoints | Removed live `ipdb`/`pdb` in `laplace.py`, `var_dtc.py`, `state_space_main.py` (raise / return controlled failure) |
| Gamma overflow | `special.gammaln` in `logpdf_link`; `pdf_link` via exp(sum(logpdf)) |
| Stationary distances | Direct pairwise differences in `_unscaled_dist` (translation-invariant; exact `r=0` for coincident points) |
| Exp/OU `K(X,X2)` | Same distance fix |
| Bernoulli / Probit | Latent-space `log_ndtr` logpdf + derivatives; stable EP variance rewrite for `z<0` |
| Softplus | `np.logaddexp(0, f)` |
| Cloglog | `-expm1(-exp(f))` with large-`f` short-circuit |
| `jitchol` | Raise `LinAlgError` on non-finite input before LAPACK |
| Poisson deep negative `f` | Log-link overrides: `-e^f + y f - gammaln` in latent space |
| Bound gradients | Finite lengthscale gradient at Logexp floor (`0` instead of NaN) |
| DiffKern at subnormal `ℓ` | Clip `_scaled_dist` and `1/ℓ` powers (`_safe_inv_lengthscale`); zero non-finite RBF/StdPeriodic X-derivatives so DiffKern stays finite when Logexp drives `ℓ→0` |

Distance work is Python-path only on this branch (Cython distance was never
the hot path; Cython grads remain as on `main`). CIP-000E's pure-Python
tree should pick up the same `_unscaled_dist` change when merged or
cherry-picked.

### Follow-up: DiffKern overflow after bound-gradient fix

Zeroing non-finite lengthscale gradients at the Logexp floor (bound-grad
row above) is correct for the objective, but it lets L-BFGS **accept**
near-zero lengthscales that previously aborted on NaN grads. At
`ℓ ~ 1e-300`, DiffKern evaluates RBF/StdPeriodic X-derivatives that form
products of `1/ℓ²` factors; those overflow to NaN before multiplying by
`K≈0`. On Windows Python 3.11 (PR #1313), `test_MultioutputGP_gradobs_prod_mix`
then failed post-`optimize` `checkgrad`; Ubuntu/macOS 3.11 and other
Windows Pythons stayed green. Fix: clip scaled distance and inv-lengthscale
powers, map non-finite derivative entries to 0, and guard with
`test_rbf_diffkern_finite_at_subnormal_lengthscale`. Not LQ-related —
stationary / DiffKern path only.

### Cross-check vs cythonless (CIP-000E)

Before these fixes, CIP-0011 `compare.py` of `main` vs
`cip000E-numpy-blas-primitives` was **outcome-identical** (0 diffs, 20
shared xfails) — recorded under
`benchmarks/cip000E/results/numerical_stability_main_vs_branch.md` on
the CIP-000E branch. Dropping Cython alone did not clear the catalogue;
these CIP-0012 patches do.

## Backward Compatibility

- Behaviour changes are **corrections** toward mathematically expected
  values (e.g. softplus no longer saturates at 709; Bernoulli tails are
  accurate). Callers that relied on the old clipped / saturated values
  will see different numbers — intentionally.
- Raising on non-finite `jitchol` input turns silent NaN likelihoods into
  earlier exceptions.
- Unit test `test_log_ex_1_overflow` updated to the softplus asymptote.
