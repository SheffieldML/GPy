## Summary

Triage the long-lived open pull requests on SheffieldML/GPy (everything open before the October 2026 Raashish batch). Cluster them, map each cluster to a CIP or backlog item, close superseded noise, and leave a clear invitation on each remaining PR so authors and maintainers know the intended next step.

Recent PRs excluded from this triage (handle separately as merge candidates):

- #1124 WarpedGP serialization
- #1125 Gamma / Laplace gradients
- #1127 SparseGPRegression serialization
- #1128 GPRegression.load_model return type

## Motivation

The open PR list had accumulated years of good-faith work with little disposition. Leaving PRs open without a design owner creates false hope for authors, hides real bugs behind merge conflicts, and duplicates effort (especially packaging). VibeSafe gives us CIPs (HOW) and backlog tasks (DO) so community-driven review can resume without pretending every stale branch is merge-ready.

### Process rules for this triage

1. **Comment before close.** Every close cites this CIP and thanks the author.
2. **Do not force-push contributor branches.** Prefer backlog tasks that re-implement or ask authors to rebase.
3. **Merge only after green CI on current `devel`.** Stale mergeable flags are not enough.
4. **One design owner per cluster.** Packaging stays under CIP-0003; do not accept parallel competing packaging PRs.
